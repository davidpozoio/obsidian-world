# Ecosystem
the java ecosystem is formed by the next:
- JVM (java virtual machine)
- JRE (java runtime environment)
- JDK (java development kit)
![[Excalidraw/Drawing 2025-09-08 16.23.51.excalidraw|700]]
## JVM (java virtual machine)
It's an environment that allow us to execute a java application in any computer.
## JRE (java runtime environment)
This part of the java ecosystem is in charge of including all the tools to run a java application, this part is specially used when we need to run a java application but we don't need to compile it.
## JDK (java development kit)
This offers us all the toots that we need to develop (compile) and run a java application.

This tool allow us to handle different versions of open jdk. To install this tool you follow the documentation steps [sdkman documentation](https://sdkman.io/).
# Important commands
To list all java versions
```bash
sdk list java
```
Install a java version
```bash
sdk install java $version_number
```
Show current version of java
```bash
sdk current java
``` 
Change java version
```bash
sdk use java $version_number
```
